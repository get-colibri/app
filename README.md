## 🌟 What is Colibri?

**Colibri** is a collaborative Markdown editor that integrates seamlessly with GitHub repositories. Open any `.md` file, edit in real time with your team, and merge it back as a clean pull request.

**Everything you love about Google Docs, integrated into your GitHub workflow.**



## ✨ Features

### 🔄 Live Collaboration
Work seamlessly together with your team in real-time. Multiple users can edit the same markdown document simultaneously, with changes appearing instantly for everyone.

### 🌍 Share with Anybody
No account required for collaborators - just share the link and start editing together. Perfect for external contributors, documentation reviews, and community projects.

### 🔗 Git Sync
Frictionless GitHub workflow. All changes made in Colibri are automatically synced back to your repository as clean pull requests. No more copy-pasting or manual merge conflicts.

### 💬 Inline Comments
Perfect for async workflows and code reviews. Add inline comments, discuss changes, and resolve feedback directly within the markdown document.


## 🚀 Get Started

### No Setup. No Configuration. Just Use It.

Simply replace `github.com` with `tune.github.com` in any markdown file URL:

```
# Original GitHub URL
https://github.com/org/repo/document.md

# Colibri collaborative editing URL
https://tune.github.com/org/repo/document.md
```

That's it! You're now in Colibri, ready to collaborate in real-time.
